Privacy policy

Last updated 23 September 2026

heph-content is a private command-line tool used by the owner of the Loiter Mode and Pastlight YouTube channels to upload and manage videos on those two channels. It has one user: the channel owner. It has no website login, no accounts for other people, and it is not offered to the public. Using the tool means agreeing to this policy and to the terms of service.

YouTube API Services

heph-content uses YouTube API Services (the YouTube Data API v3). By using it, you agree to be bound by the YouTube Terms of Service. Google's handling of your data is described in the Google Privacy Policy.

What data the tool accesses

The channel owner authorises the tool once per channel with Google OAuth. With that authorisation, and only for the owner's own two channels, it:

  • uploads videos with the title, description, tags, category, language, privacy setting (private or unlisted; never public by default), the "made for kids" and "altered or synthetic content" declarations, and an optional scheduled publish time;
  • sets thumbnails and adds videos to the owner's playlists;
  • makes one video public only when the owner types the video's title back to confirm;
  • updates channel branding: banner image, channel description and keywords, and the video watermark;
  • reads the channel's ID, title and branding settings, the channel's playlists, and the title, file size and original file name of the channel's 50 most recent uploads, and the title and privacy settings of a video before it is made public. These reads check that the right channel is authorised, that a playlist belongs to the channel, and that a video is not uploaded twice. The results are used during that run and are not saved.

The tool does not access viewers' data, comments, messages, subscribers' identities, YouTube Analytics or revenue data.

What data the tool stores

DataWhereHow long
OAuth refresh token for each of the two channels, with the channel ID, channel title and granted scopes An encrypted secrets store on the owner's own private infrastructure. Short-lived access tokens are held in memory only for the length of one command. Until access is revoked (see below).
One small upload record per video: the channel and video ID, a checksum and size of the video file, a checksum of the metadata sent, the resumable-upload session address, the upload status, the scheduled publish time, the declarations sent, and which thumbnail and playlists were applied A file next to the video on the owner's own computer, readable only by the owner's account. Only as long as needed to finish that upload; deleted or re-checked against YouTube within 30 days.

Nothing else is stored. Tokens and client secrets are never written to the upload records.

How the data is used and shared

The data is used only to publish and manage videos on the owner's two channels. It is not shared with anyone, internally or externally, and is not sold. It is not used for advertising or profiling. The use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

The tool does not let third parties serve content or advertisements.

Cookies and device information

The tool runs on the owner's own computer. Neither the tool nor this website sets cookies, uses analytics or tracking, or collects information from your device. This website is hosted on GitHub Pages; GitHub may record visits as described in its own privacy statement.

Revoking access

You can revoke heph-content's access to your Google account at any time on Google's security settings page: https://security.google.com/settings/security/permissions. Once access is revoked the stored refresh token no longer works, and the tool can no longer read or change anything on the channel.

Deleting your data

In addition to revoking access, you can ask for all stored data about you to be deleted by opening an issue on this site's repository. Stored data is deleted within 7 days of a request, and within 7 days after access is revoked: the stored token is removed from the secrets store and the upload records for that channel are deleted. Deleting a video from YouTube itself is done in YouTube Studio.

Contact

Questions or complaints about these privacy practices: open an issue on github.com/PlaidPiper/channels.
